# Security

The cooldown switches a chamber heater, a bed heater and fans, and can leave them running
for hours. A bug that can leave a heater on is a safety problem and worth reporting even
when nothing went wrong on your printer.

Report it in a public issue on this repository. Reports are public on purpose: anyone
who runs the same macros should be able to see the problem and the fix. Give the versions
of this repository and of Klipper-Hardware-Controls, the firmware (Klipper or Kalico) and
what you did.

Supported: the latest release and `main`.
