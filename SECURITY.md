# Security

The cooldown switches a chamber heater, a bed heater and fans, and can leave them running
for hours. A bug that can leave a heater on is a safety problem and worth reporting even
when nothing went wrong on your printer.

Report it privately with the "Report a vulnerability" button on the Security tab of this
repository, not in a public issue. Give the versions of this repository and of
Klipper-Hardware-Controls, the firmware (Klipper or Kalico) and what you did.

Supported: the latest release and `main`.
